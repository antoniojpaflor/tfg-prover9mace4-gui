Bienvenido a la documentación técnica de la Interfaz Gráfica de Usuario para los motores lógicos Prover9 y Mace4. Este software ha sido desarrollado como Trabajo de Fin de Grado para el Grado en Ingeniería Informática de la Universidad de Granada (UGR).\hypertarget{index_arch_sec}{}\doxysection{\texorpdfstring{Arquitectura del Sistema}{Arquitectura del Sistema}}\label{index_arch_sec}
La aplicación está construida utilizando Python y Py\+Qt6, siguiendo un patrón modular y escalable\+:
\begin{DoxyItemize}
\item {\bfseries{\doxylink{main_8py}{main.\+py}}}\+: Orquestación central, resaltado de sintaxis y gestión de eventos de la interfaz.
\item {\bfseries{\doxylink{launcher_8py}{launcher.\+py}}}\+: Capa de abstracción para la ejecución segura de subprocesos multiplataforma.
\item {\bfseries{\doxylink{idiomas_8py}{idiomas.\+py}}}\+: Base de datos estática para la internacionalización y configuración estructural.
